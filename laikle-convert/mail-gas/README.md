# 変換完了メールの設定手順（Google Apps Script）

laikle-convert で変換が完了したときに、`ec@elcommun.co.jp` へ自動でメールを送るための設定です。
**最初に1回だけ**行えば、以降は何もしなくても自動送信されます（所要5〜10分）。

作業には、送信元にしたいGoogleアカウント（Gmail）でのログインが必要です。

---

## 手順

### 1. Apps Script のプロジェクトを作る

1. ブラウザで <https://script.google.com/home> を開く（送信元にしたいGoogleアカウントでログイン）
2. 左上の **「新しいプロジェクト」** をクリック
3. 画面に出ているサンプルコード（`function myFunction() {}` など）を**すべて削除**する
4. このフォルダの `Code.gs` の中身を**すべてコピーして貼り付ける**
5. 左上のプロジェクト名（「無題のプロジェクト」）をクリックし、`laikle-convert メール送信` などに変更
6. 💾 保存（⌘S）

### 2. ウェブアプリとしてデプロイする

1. 右上の **「デプロイ」** → **「新しいデプロイ」** をクリック
2. 左上の歯車マーク ⚙️ → **「ウェブアプリ」** を選択
3. 次のように設定する
   - **説明**：（任意。「laikle-convert メール」など）
   - **次のユーザーとして実行**：**自分**（自分のメールアドレスが表示されているもの）
   - **アクセスできるユーザー**：**全員** ← ここが「自分のみ」だとアプリから送信できません
4. **「デプロイ」** をクリック
5. 「承認が必要です」と出たら **「アクセスを承認」** → 自分のアカウントを選択
   - 「このアプリは Google で確認されていません」と出たら、**「詳細」** → **「（プロジェクト名）に移動（安全ではないページ）」** をクリック
   - 内容（メールの送信）を確認して **「許可」**
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を**コピー**する

### 3. アプリにURLを設定する

コピーしたURLをチャットで共有してください。こちらで `laikle-convert/index.html` の
`MAIL_WEBHOOK_URL` に設定し、動作確認のうえ反映します。

（ご自身で設定する場合は、`laikle-convert/index.html` 内の
`const MAIL_WEBHOOK_URL = '';` の `''` の中にURLを貼り付けて、`APP_VERSION` を1つ増やしてコミットします）

---

## 動作確認

- ウェブアプリのURLをそのままブラウザで開くと `{"ok":true,"message":"laikle-convert mail webhook is running"}` と表示されます
- アプリ側の設定が済むと、変換完了時にログへ「📧 完了メールを ec@elcommun.co.jp に送信しました」と表示されます

## メールの内容

件名：`【laikle-convert】変換が完了しました`

本文：日時／変換商品数／URL置換箇所／商品画像数／変換もれ件数

## 補足

- メールはページを開いてから**最初の変換完了時に1通だけ**送信されます（何度も変換し直しても連続送信されません）
- 送信先を変えたいときは `Code.gs` の `MAIL_TO` を書き換えて、**「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」** で更新します（URLは変わりません）
- Gmailの1日あたりの送信上限（無料アカウントで100通程度）の範囲内で動作します
