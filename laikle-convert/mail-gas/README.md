# 変換完了メールを使えるようにする（初回だけの設定）

変換が終わったときに `ec@elcommun.co.jp` へ自動でメールが届くようにします。
**最初に1回だけ**この設定をすれば、あとは何もしなくても自動で送信されます。

かかる時間：**5〜10分**
用意するもの：**メールの送信元にしたいGoogleアカウント（Gmail）**

> なぜこの作業が必要？
> このアプリはサーバーを持たないため、アプリ単体ではメールを送れません。
> Googleの無料サービス（Apps Script）に「メールを送る係」を1つ作って、そこにお願いする形にします。

---

## ステップ1：メールを送る係（プロジェクト）を作る

1. ブラウザで **<https://script.google.com/home>** を開きます
   - 送信元にしたいGoogleアカウントでログインしてください
2. 左上の **［＋ 新しいプロジェクト］** をクリックします
3. 画面の真ん中に、こんなサンプルのコードが出ています

   ```
   function myFunction() {
   }
   ```

   これを **全部消します**（クリックしてから ⌘A → delete）

4. このフォルダにある **`Code.gs` の中身をすべてコピーして、消したところに貼り付けます**
   - GitHub上のファイル: [Code.gs](./Code.gs)
   - 右上のコピーボタン、または ⌘A →⌘C で全選択コピーできます
5. 画面上部の **💾（保存）** をクリック（または ⌘S）
6. 左上の「無題のプロジェクト」をクリックして、**`laikle-convert メール送信`** など分かりやすい名前に変えます

---

## ステップ2：使えるようにする（デプロイ）

「デプロイ」は、作ったものを**外から使える状態にする**作業です。

1. 画面右上の **［デプロイ］** → **［新しいデプロイ］** をクリック
2. 左上にある **⚙️（歯車）** をクリック → **［ウェブアプリ］** を選びます
3. 次のように設定します（**ここが一番大事です**）

   | 項目 | 選ぶもの |
   |---|---|
   | 説明 | 空欄でOK（「laikle-convert メール」などでも可） |
   | 次のユーザーとして実行 | **自分**（自分のメールアドレスが表示されているもの） |
   | アクセスできるユーザー | **全員** ← ⚠️「自分のみ」だと動きません |

4. **［デプロイ］** をクリック

---

## ステップ3：許可する（初回のみ表示されます）

「承認が必要です」という画面が出たら、次のように進みます。
※ 見慣れない警告が出ますが、**ご自身で作ったスクリプト**なので問題ありません。

1. **［アクセスを承認］** をクリック
2. 自分のGoogleアカウントを選択
3. **「このアプリは Google で確認されていません」** と出たら
   - 小さい文字の **［詳細］** をクリック
   - 一番下の **［(プロジェクト名) に移動（安全ではありません）］** をクリック
4. 「メールの送信」などの内容を確認して **［許可］** をクリック

---

## ステップ4：URLをコピーして共有する

1. デプロイが終わると、こんなURLが表示されます

   ```
   https://script.google.com/macros/s/AKfy……（長い文字列）……/exec
   ```

2. 右側の **［コピー］** をクリックしてコピーします
3. **このURLをチャットに貼り付けて送ってください**
   - こちらでアプリに設定し、テストして完了報告します

以上で作業は終わりです。おつかれさまでした 🎉

---

## うまくいったか確認したいとき

コピーしたURLを、そのままブラウザのアドレス欄に貼り付けて開いてみてください。
次のように表示されれば成功です。

```
{"ok":true,"message":"laikle-convert mail webhook is running"}
```

アプリ側の設定が終わると、変換したときにログへ
**「📧 完了メールを ec@elcommun.co.jp に送信しました」** と表示されるようになります。

## よくある質問

**Q. 変換するたびに何通も届きますか？**
A. いいえ。ページを開いてから**最初の1通だけ**です。変換をやり直しても、そのたびに送られることはありません。

**Q. 送信先を変えたくなったら？**
A. `Code.gs` の `MAIL_TO = 'ec@elcommun.co.jp'` の部分を書き換えて保存し、
**［デプロイ］→［デプロイを管理］→ 鉛筆マーク ✏️ → バージョン「新バージョン」→［デプロイ］** で更新します（URLは変わりません）。

**Q. メールは誰から届きますか？**
A. ステップ1でログインしたGoogleアカウントから送信されます。

**Q. 送りすぎで止まったりしませんか？**
A. Gmailの1日あたりの送信上限（無料アカウントで100通程度）の範囲内で動きます。1日1通程度の利用なら問題ありません。
