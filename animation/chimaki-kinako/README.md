# いつも、となりに。 〜ちまきと、きなこ〜（60秒 2Dアニメーション）

ソファのいちばん上が定位置のポメチワ「ちまき」と、その下でへそ天するダックス「きなこ」。
「どうしていつも、そこにいるの？」——その答えは、きなこが家に来た雨の夜にありました。
そして嵐の夜、今度はきなこが、あの日のブランケットを持ってちまきのもとへ。

- `index.html` … ブラウザ上でリアルタイム描画するプレイヤー
- `chimaki-kinako.mp4` … 書き出し済み動画（1920×1080 / 30fps / 60秒）
- `scene.js` … 描画エンジン（キャラクター・部屋・天気・回想演出まですべてコード）
- `photo.jpg` … ラストに登場する、ちまきときなこの本物の写真
- `src/` … 脚本・音声生成・作曲/効果音合成・フレーム書き出しのスクリプト
