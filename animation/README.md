# ほしのおとしもの（60秒 2Dアニメーション）

夜の丘で星を見ていた小さなロボット「ポコ」のもとに、流れ星の女の子「キラ」が落ちてくる。
夜明けまでに空へ戻らないと消えてしまうキラのために、ポコは町じゅうの灯りを「光のらせん階段」に変えて――。

- `index.html` … ブラウザ上で**リアルタイム描画**するプレイヤー（動画ではなくCanvasコードが毎フレーム絵を描く）
- `hoshi-no-otoshimono.mp4` … 書き出し済み動画（1920×1080 / 30fps / 60秒 / AAC音声）
- `scene.js` … 全シーンの描画エンジン（画像素材ゼロ。時刻 t の純粋関数）
- `lipsync.js` … 音声波形から算出した口パクデータ（30fps）
- `soundtrack.m4a` … セリフ＋BGM＋効果音のミックス
- `src/` … 制作パイプライン（脚本JSON、音声生成、作曲・効果音合成、ミックス、フレーム書き出し）

## 制作方法
| 要素 | 手法 |
|---|---|
| 映像 | Canvas 2D をコードで描画 → Playwright(Chromium)で1800フレーム書き出し → ffmpeg(H.264) |
| 声 | VOICEVOX（voicevox_core 0.16）。感情ごとに話速・抑揚・音量を調整 |
| 口パク | 各セリフのRMS音量エンベロープ → 口の開き |
| 音楽 | numpy/scipy による完全な手続き合成（オルゴール・チェレスタ・弦・ホルン・ティンパニ、畳み込みリバーブ） |
| 効果音 | 同上（流れ星、衝突、ロケット、ボヨン、光の粒、星座完成のチャイム、夜明けの鳥） |
