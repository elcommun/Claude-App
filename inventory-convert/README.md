# 在庫データ変換 — 売上xlsx → SKU・総在庫数CSV

`index.html` 一枚のシングルページアプリ。
EC在庫の**売上データ（xlsx）**を、**「SKU」「総在庫数」の2列のみのCSV**に変換する。

公開URL: `https://elcommun.github.io/Claude-App/inventory-convert/`

## 使い方

1. **ファイルをアップロード**（2つとも必須）
   - **売上データ xlsx**: 「商品コード」「売上数」列を含む販売管理システムの売上明細（「商品名１」列があればプレビューに表示）
   - **itemdata CSV**: GoQ System からダウンロードした在庫連携CSV（「システム連携用SKU番号」「SKU管理番号」列を使用。Shift-JIS/UTF-8自動判定）
2. **変換を実行** ボタンを押す
3. プレビューで結果を確認し、**CSVをダウンロード**（文字コードは Shift-JIS 推奨／UTF-8 BOM付きも選択可）

## 変換ルール

- xlsx の**商品コード**が、itemdata の**システム連携用SKU番号の末尾**に一致する行を探し、その行の**SKU管理番号**を「SKU」として出力する
  - 例: 商品コード `5A-CE-001` → システム連携用SKU番号 `elco-5ace001-5A-CE-001` に一致 → SKU管理番号（`5A-CE-001` や `9490` などの数値の場合もある）を出力
- **総在庫数** = xlsx の**売上数**の頭に `+` を付けた値（例: `+3`）
- 同一商品コードが複数行ある場合は**売上数を合算**（プレビューに「合算」バッジ表示）
- **一致しない商品コード**、または**複数の異なるSKUに一致**した商品コードは、エラーとしてプレビュー最上部に赤色表示し、**出力CSVには含めない**

## 出力形式

```csv
SKU,総在庫数
5A-CE-091,+1
ALA-004,+10
9490,+2
```

- 1行目はヘッダー `SKU,総在庫数`、改行はCRLF
- デフォルトは Shift-JIS（Excelで開いても文字化けしない）。UTF-8選択時はBOM付き

## バージョン番号

`index.html` の `const APP_VERSION = N;`（フッターの `#verBadge` に `vN` 表示）。
**このファイルを変更してコミットするたびに必ず1つ増やすこと。**
3分ごとにサーバー側と比較し、大きければ自動リロード（ファイル読み込み済みのときはリロードしない）。

## 使用ライブラリ（CDN）

- SheetJS `xlsx@0.18.5`（xlsx解析）
- `encoding-japanese@2.0.0`（Shift-JIS判定・変換）
