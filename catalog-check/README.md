# カタログ校正チェック

カタログPDFの記載内容（品番・JANコード・バリエーション名・価格）を、正しい情報のExcelマスタと自動照合するツール。

## 使い方

1. 商品マスタExcel（.xlsx）をアップロード
   - 全シートを走査し、「品番」と「JAN（またはインストアコード）」を含むヘッダー行を自動検出
   - 品名・上代・廃盤列も自動で読み取り
2. カタログPDFまたはページ画像（JPG/PNG/WebP）をアップロード（複数可・容量上限なし。50MB超のPDFも動作確認済み）
3. 「照合チェックを実行」

## チェック内容

| 種別 | 内容 |
|---|---|
| JANチェックデジット | EAN-13のチェックデジット検証 |
| JAN組合せ不一致 | 記載JANが別商品のもの（貼り違い・並び違い検出） |
| JAN不一致 / 未登録 | マスタとの照合 |
| 印字JANとバーコード不一致 | バーコード（EAN-13）を直接読み取り、印字JANと突き合わせ |
| 品番誤り疑い | 1文字違いの品番を検出し候補を提示 |
| バリエーション並び違い疑い | 品番下の名称が同ブロック内の別商品のもの（画像・ラベルの並び違い検出） |
| バリエーション配置順の相違 | 同ページの他の商品グループとバリエーションの並び順（＝画像の並び）が逆 |
| 商品画像の入れ違い疑い | 画像の色味を他グループの同名バリエーションと比較し、2商品の画像だけが入れ替わっているケースを検出 |
| 税抜価格不一致 | マスタ上代との照合 |
| 税込計算不一致 | 税込＝税抜×(1+税率) の検証（税率は10%/8%を選択可） |
| 廃盤品掲載 | 廃盤マークのある商品の掲載を警告 |
| 品番並び順 | ブロック内で品番が昇順でない場合に参考情報 |
| 文章の簡易チェック | 括弧の開閉不一致・重複語（参考） |
| 低解像度ページ | ページ全体が200dpi未満の画像として埋め込まれているPDFページ／幅1500px未満の画像ファイル。小さなJAN・価格・バーコードが読めない原因になるため参考として報告 |

## 技術メモ

- 文字がアウトライン化されたPDF（Illustrator入稿データ等）はテキスト抽出できないため、**Tesseract.js（jpn+eng）によるブラウザ内OCR**で読み取る（約300dpi相当でレンダリング）
- テキストレイヤーがあるPDFはOCRを使わず直接抽出（高速・高精度）
- JANは印字のOCRに加え、ラベル下のバーコード（EAN-13）をZXingで直接読み取る（印字が極小の総合カタログ対応）。バーコードが読めた場合はそちらを優先
- 価格行は「ブロックの下」（リーフレット型）と「ブロック上の見出し行」（総合カタログ型）の両レイアウトに自動対応。一覧ページのセルごとの価格にも対応
- SOLD OUTの黒帯はピクセル解析で検出（バーコードの縞や黒い商品写真は除外）
- pdf.jsのオペレータリストからベクター描画が無く画像だけのページを検出し、埋め込み画像の画素数から有効dpiを算出（`detectRasterPage`）。例: A4に815px幅の画像＝約99dpi → バーコードのモジュール幅が1px前後になり復号不能、JAN数字は約3pxで判読不能
- OCRには誤認識の可能性があるため、結果は目視確認前提。OCRの自信が低い箇所はプレビューにオレンジ表示
- 画像入れ違いの検出は「品番ラベル上の画像領域の代表色相」を同ページ他グループと比較する方式。同色系バリエーション同士（例: ピンクと薄紫）の入れ違いは検出できない場合がある
- `window.DEBUG_TK` に検出状態（価格行・品番・行テキスト・色相）が残るため、誤検知の調査時はコンソールから確認できる
- ライブラリはすべて `lib/` に同梱（CDN不使用）: SheetJS 0.18.5 / Tesseract.js 5.1.1 + LSTMコア / jpn・eng traineddata / ZXing 0.21.3（バーコード）。pdf.js は `../design-preview/lib/` を共用
- 処理はすべてブラウザ内で完結し、データは外部送信されない
